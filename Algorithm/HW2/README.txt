알고리즘특론 HW2 — 문제 4 실험 입력

1. 파일 구성
R_200.txt: 무작위 입력, 삽입 키 200개 / 실패 질의 200개
R_800.txt: 무작위 입력, 삽입 키 800개 / 실패 질의 800개
C_200.txt: 충돌 집중 입력, 삽입 키 200개 / 실패 질의 200개
C_800.txt: 충돌 집중 입력, 삽입 키 800개 / 실패 질의 800개
모든 파일에서 테이블 크기 m은 1009

2. 파일 형식
첫째 줄: m n
둘째 줄: 삽입할 키 n개 (공백으로 구분, 나열된 순서대로 삽입)
셋째 줄: 실패 탐색 질의 n개 (공백으로 구분, 나열된 순서대로 탐색)
성공 탐색에는 둘째 줄의 키를 같은 순서로 다시 사용
각 파일의 키와 실패 질의는 모두 서로 다른 0 이상의 정수
키 0은 유효하므로 테이블의 빈칸과 구분할 것

3. 실행 방법
- 각 파일에 대해 선형 탐사와 이중 해싱을 각각 실행 (총 8개 조건).
- 매 조건은 빈 테이블에서 시작
- 둘째 줄의 키를 모두 삽입한 뒤, 테이블을 변경하지 않고 성공 탐색 질의와 실패 탐색 질의를 각각 1회씩 수행
- 두 방식에 동일한 키와 질의 순서를 사용

4. 입력 생성 규칙 (새로 생성하지 말 것)
R 입력: n별로 Python random.Random(2026)을 새로 생성한 뒤, sample(range(10**7), 2*n)을 실행
추출된 순서를 유지하여 앞 n개는 삽입 키, 뒤 n개는 실패 질의로 사용했습니다.
C 입력: i=0,...,n-1의 오름차순으로 삽입 키 k_i=1009*i, 실패 질의 q_i=1009*(n+i)를 생성

5. 제출 안내
